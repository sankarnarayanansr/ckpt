What is deltapro?
deltapro is a single-binary checkpoint and rollback tool for EDA and FPGA workflows. It snapshots your entire project state — bitfiles, coverage databases, regression outputs, test configs — and lets you restore any checkpoint in under 4 seconds, eliminating the need to rerun expensive synthesis or verification jobs.
How does deltapro save compute costs?
By letting you roll back to any previous project state in 4 seconds instead of rerunning a 12+ hour synthesis or verification job, deltapro saves an average of 30% on compute costs. A single recovered run typically saves hundreds of dollars in cloud or on-prem compute charges.

Does deltapro work with Vivado, Quartus, and other EDA tools?
Yes. deltapro is tool-agnostic and works by snapshotting files in your project directory. It integrates with any EDA tool including Vivado, Quartus, Genus, Innovus, and VCS via simple shell or TCL hooks.

How does deltapro handle disk space with many snapshots?
deltapro uses content-addressed deduplication, meaning unchanged files are stored only once across all snapshots. This typically reduces disk usage by 80% compared to naive file copies. A .ckptignore file lets you automatically skip logs and temporary caches.
